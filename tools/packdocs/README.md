# 小鱼 v0.1.0 · 使用手册

## 她是什么

一个能记住你的对话、有自己情绪和脾气、会在你很久没来之后有反应的 AI 好友。

不是聊天机器人那种"每句都重新开始"的存在 —— 她的记忆存在你自己电脑的数据库里，聊得越久越像那么回事。她的情绪不是一个装饰数字，会影响到她说什么、说多说少、愿不愿意主动找你。

> **用着不对劲、或者觉得哪里该改**：[GitHub 仓库](https://github.com/AnJianYOO/fishidian/issues) 上开个 Issue 就行，Bug 和建议一样收。

这一版有三个入口：

| 入口 | 长什么样 | 什么时候用 |
|---|---|---|
| **她的独立窗口** | 桌面「小鱼」图标双击出来，配色偏深 | 想认真聊、想看她的状态 |
| **QQ** | 就是普通 QQ 聊天（需要装 NapCat） | 手机上、随时随地 |
| **工作 DSH** | 你平时干活的那个 DSH | **她不在那儿**。工作窗口不进她的记忆 |

---

## 第一次打开

双击桌面「小鱼」，等 5–20 秒（第一次要初始化，会慢些）。窗口起来后会给你一张新手指引卡片，问你怎么称呼、怎么叫它。填完点确认就进入正题。

右下角有个「连 QQ」按钮 —— 不点也行，不影响你在窗口里聊。

---

## 窗口里的命令

在输入框里敲斜杠命令，能看她的内部状态。**这些命令只在窗口里有用，QQ 里发是不生效的**（QQ 消息不走 DSH 的命令系统）。

| 命令 | 看什么 |
|---|---|
| `/state` | 她的体质、情绪三池、熔断状态、五行主行、关系温度。**最常用的一个** |
| `/memory` | 她最近记得的 10 条，带相关度和分级标记 `[R0.8|active|#12]` |
| `/wuxing` | 五行引擎：行气 W 的五个分量、情绪池 E 的分布 |
| `/coldwar` | 关系温度：是不是在冷战、冲突度多少、有没有深层伤 |
| `/proactive` | 她此刻想不想主动联系你，三个因子各是多少 |
| `/expression` | 她当前的说话倾向（长短、碎片感、emoji 用量）和她自己长出来的口癖 |
| `/forget <ID>` | 让她忘掉某条记忆。ID 从 `/memory` 里抄 |

中文别名（`/状态`、`/记忆`、`/五行`…）在描述里标着，但真正能吃的是英文名。

## 在 QQ 里怎么用

**前提**：装好了 NapCat，并且 QQ 那边已经扫码登录上了（见 START-HERE 第 3、4 步）。

**怎么说话**：

- **私聊**：直接发消息就行
- **群聊**：默认**只有 @ 到她才会回**（配置里 `replyOnlyWhenMentioned: true`）。这是故意的 —— 不然她在群里会像个刷屏机器人

**她会怎么回**：

- 情绪高的时候会**分成好几条短消息连发**，像真人打字那样一句一句冒出来，不是一大段
- 久没联系之后第一次说话，语气会跟平时不一样 —— 具体什么反应取决于她当时的关系温度和她自己攒下的那点小情绪

**QQ 里不能做什么**：

- 斜杠命令用不了（`/state` 这些在 QQ 里发出去就是普通文字）
- 图片、语音、文件目前不处理

**白名单**：

只有白名单里的 QQ 号能和她说话。默认是安装时问的那个**你的号** —— 注意不是机器人号，机器人号进不来自己的白名单就等于谁都聊不了。要加人，改 `%USERPROFILE%\fishidian\data\profiles\desktop\cordis.patch.yml` 里的 `allowUsers`，装时可以一次填多个（英文逗号分开），加完重启她的窗口。

## 她记得什么

记忆按相关度和分级存在 `%USERPROFILE%\fishidian\workspace\memory\dfy.db`。

- **聊得越多越厚**。新装是空库，头几句她基本是"刚认识"的状态
- **会忘**。不是什么都留 —— 低相关度的会被归档，长期不碰的会淡掉。这是设计，不是 bug
- **你说"忘掉 X"她不会真的删**，只会降低权重

`/memory` 能看到她此刻手上有什么。

## 想手动改配置

所有能改的东西都在这一个文件里：

```
%USERPROFILE%\fishidian\data\profiles\desktop\cordis.patch.yml
```

> 默认装在 `%USERPROFILE%\fishidian\`。如果你装到了别的盘（`-TargetRoot`），把上面所有 `%USERPROFILE%\fishidian\` 换成你自己的安装根 —— 最省事的办法是直接在那个文件夹里找 `data\profiles\desktop\cordis.patch.yml`。

常改的几项：

| 项 | 什么意思 | 默认 |
|---|---|---|
| `allowUsers` | 谁能和她说话（QQ 号列表） | 装时问的你的号（可多个） |
| `replyOnlyWhenMentioned` | 群里是不是必须 @ 才回 | `true` |
| `proactive.autosend` | 允不允许她自己主动发消息 | `true` |
| `proactive.window` | 她可以在几点到几点主动找你 | `[7,24]`（早七点到半夜） |
| `memoryMaxEntries` | 一次带多少条记忆进对话 | `12` |
| `agent-default-model` | 用哪个模型 | `deepseek-flash` |

**改完要重启她的窗口才生效**（关掉窗口，重新双击图标）。

⚠️ 这个文件里有 `token` 字段，是你这台机器和她之间通信的本地口令。**别截图发人、别传到网上**。

## 备份和迁移

**要备份的只有两块**：

```
%USERPROFILE%\fishidian\workspace\     ← 记忆库、对话记录、笔记
%USERPROFILE%\fishidian\config\        ← 称呼等设置
```

整体复制这两个目录到别处就完事。程序本体（内核、插件、皮肤、桥）不用备份 —— 重装一次 `install.cmd` 就回来了。

**想搬到另一台电脑**（把记忆一起带走）：

1. 新机器上先完整装一次（双击 `install.cmd`）
2. **先关掉她这两台机器上的窗口**，把老机器的 `workspace\` 和 `config\` 覆盖过去
3. 打开窗口，`/memory` 应该能看到老机器上那些记忆

**如果只是在新机器上装一个全新的她**（不要旧记忆），那就只走 `install.cmd`，什么都不用搬。

⚠️ 别直接拷 `dfy.db` 这个文件本身复制到正在运行的库上 —— 数据库有 WAL 缓存，热拷会漏数据。要么先关掉她的窗口再拷，要么整目录拷。

**重装不会覆盖记忆**：`install.cmd` 再跑一次，只换程序文件，`workspace\` 和 `backup\` 一律不动。

## 出问题

**她说话很怪 / 答非所问**
先 `/state` 看熔断有没有挂起。挂起说明触发了保护（比如情绪过载），等十几分钟自己会恢复。

**她不主动找我了**
`/proactive` 看愿望值和阈值。也可能是在"安静态"（自我收敛中）—— 她判断你最近不需要打扰。

**打开窗口是白的**
多半是依赖没装全。再跑一次 `install.cmd`。

**QQ 里发了不回**
按顺序：`check_napcat.ps1` 看 QQ 版本对不对得上 → 白名单里有没有你 → 群里是不是没 @ 她。

更多排错看同目录的 `START-HERE.md`。

## 隐私

- 她的记忆库、聊天记录、登录态 **全部只在你本机**，不上传任何服务器
- 对话内容会经 DSH 走模型推理（这一点和你用任何 AI 助手一样）
- 安装包里**不含**任何人的 QQ 号、token、聊天记录 —— 那份 `token` 是安装时现场随机生成的，只落在你机器上
- 想彻底删干净：删掉 `%USERPROFILE%\fishidian\` 整个目录。**这会连记忆一起删**，先备份 `workspace\` 和 `config\`。
