# 文档

这里是设计文档，写给想读懂代码、想自己改的人。**只想用的话不用看** —— 装完看安装根里的 `START-HERE.md` 就够了。

哪份写错了、哪句看不懂，去 [GitHub 仓库](https://github.com/AnJianY00/fishidian/issues) 开个 Issue 说一声就行。

## 给使用者看的那几份

面向「装完想用」而不是「想改代码」的，放在 `90_RELEASE/`：

- [`90_RELEASE/安装说明.md`](90_RELEASE/安装说明.md) —— 装之前要准备什么、装完什么样
- [`90_RELEASE/QQ桥怎么用.md`](90_RELEASE/QQ桥怎么用.md) —— QQ 怎么接、怎么换别的 OneBot 实现
- [`90_RELEASE/常见问题.md`](90_RELEASE/常见问题.md) —— 装不上、她不回，按这个查
- [`90_RELEASE/从GitHub直接安装.md`](90_RELEASE/从GitHub直接安装.md) —— 能不能不走安装包，直接在 DSH 里装插件（结论：不建议）

## 一点说明

`10_SPEC` 只写**现在是什么样**，不写「以后想做成什么样」。所以看到某处写着「未落地」并不是文档过期，是它有意的表述。
