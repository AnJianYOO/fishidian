# 安装说明

> 状态：**已对齐实装（V1）** ｜ 最后更新：2026-11-14
> 这份是给用户看的，不出现工程术语。完整版在安装包里的 `START-HERE.md`。

## 装之前

需要准备四样：

1. 这台电脑上已经装好 **DeepSeek Harness**（DSH），并且**登录过一次**
   - 不用另外准备 API Key，也不用去后台抄什么 —— 登录一次它就自己带着走了
   - 装之前要把它**连托盘一起退出**，开着装会卡在第一步
2. **Node.js 18 以上** —— 这条是硬门槛，16 装得上但 QQ 通道起不来
3. **Python 3.8 以上**（安装时要勾 Add python.exe to PATH）。敲 `python` 会弹微软商店说明装的是占位程序
4. 一个能登录的 **QQ 号**，用来当她（不想用 QQ 可以先空着）

少一样，安装器第一步就会告诉你缺哪个、去哪装，不会装一半坏掉。**版本不够也会当场拦住**，不会让你装完才发现 QQ 通不了。

## 装的时候问两句

两句都是 QQ 号，别弄混：

1. **机器人 QQ 号** —— 她的号，会登在 NapCat 上
   - 提醒一句：**这个号登在她的 QQ 上，你就不能用手机 QQ 再登同一个号**
2. **你的 QQ 号（白名单）** —— 谁有资格和她说话
   - 这里填**你自己的号**，不是上面那个机器人号
   - 想多个人用，英文逗号分开，最多 5 个
   - 不想用 QQ 的话，第一句直接回车，第二句就不会问了

**为什么单独问第二句**：V1 早期版本把白名单默认成机器人自己的号，装完看着一切正常，但在 QQ 里给她发消息**一条都不会回** —— 因为白名单里只有她自己，你不在里面。现在改成单独问你，并且填错会当场提示。

两个号都只接受 **5–12 位纯数字**；带空格、全角数字、字母会被判成填错并按未填处理，不会把坏号写进配置。

（称呼不是安装时问，是第一次打开窗口时她自己在卡片里问你。）

## 装完会看到什么

- 桌面上多一个「大肥鱼」图标
- `%USERPROFILE%\fishidian\` 这个文件夹，她的东西都在里面
- 文件夹里还有五份说明：`START-HERE.md`（从装到验收）、`README.md`（使用手册）、`FOR-AI.md`（让 AI 替你排错时给它看）、`VERSION.txt`（装了哪些模块）、`README.txt`（`workspace` / `logs` / `backup` 各放什么）。QQ 那份 `QQ桥怎么用.md` 只在压缩包里，装完不会拷进来

## 第一次打开

双击桌面「大肥鱼」，等 5–20 秒。

窗口起来后会给你一张新手指引卡片，问你怎么称呼、怎么叫她。填完就进入正题。

**这一步不需要任何授权**，也不会弹管理员权限。

## 要用 QQ 的话

按这个顺序，别跳：

1. **先装 NapCat** —— 它是让她的 QQ 连上真 QQ 的中间层，110 MB，**没有放进包里**（它必须和本机 QQ 的版本对上，硬塞一个进去你的 QQ 版本不对就白装）
   - 先双击安装根里的 `check_napcat.ps1` 体检，它会报 NapCat 和本机 QQ 两个 build 号
   - **两个数不一致不代表不能用**，先真起一次看二维码出不出来
   - NapCat 解压到 `%USERPROFILE%\NapCat`，确认里面有 `launcher.bat`
2. 回窗口右下角点「连 QQ」
   - 会出现二维码浮层。**码大概一分钟就过期**，写着"这个码可能过期了"就点一下刷新
   - 第一次会弹一次 **管理员权限**，这是 NapCat 要注入 QQ 进程，Windows 规定必须本人点
   - 手机 QQ 扫码登录

## 怎么算装对了

装完先跑一次自动验证（只读，不重装）：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "%USERPROFILE%\fishidian\verify_install.ps1"
```

它会逐项报版本、文件、插件链、QQ 配置、内核能不能跑，最后给一行汇总：**失败 0** 就是窗口这块没问题。装到别处时加 `-TargetRoot "D:\fishidian"`。

脚本判不了这四条，得自己看：

1. 窗口能开，左下栏写着「大肥鱼」，配色和你平时用的 DSH 不一样
2. 和她聊几句，`%USERPROFILE%\fishidian\workspace\memory\dfy.db` 的文件大小会变
3. 打开工作 DSH 随便说几句，再问她"我刚才在工作窗口说了什么" —— 她应该答不上来
4. 装了 QQ 的话，QQ 里给她发条消息，她会在 QQ 里回

**第 2 条没长的话，别先怀疑她忘性大。** 这版把三条路径写死在 `launch.ps1` 里（`FISHIDIAN_DB` / `FISHIDIAN_CORE` / `FISHIDIAN_PYTHON`）。不写死的时候，内核会静默地不工作：内核目录落到打包机器上的 `D:\` 路径、记忆库落到 `%USERPROFILE%\.dsh\fishidian-memory\fishidian.db`，两处都不报错，只是每轮都当第一次聊天。所以：

- 别去 `cordis.patch.yml` 找 `python` / `core` / `db` 三个键 —— 插件只读 `ns`，那三个写上去也不生效
- 要换盘就整个重装（`-TargetRoot`），不要手改配置
- `%USERPROFILE%\.dsh\fishidian-memory\` 下多出 `fishidian.db`，就是路径跑偏了，通常是从别的方式起窗口、没走桌面「大肥鱼」

## 卡住了怎么办

- 安装停在第 1 步说 DSH 在跑 → 托盘右键退出，任务管理器里 `DeepSeek Harness` 也要清零
- 卡在装依赖 → 九成是网络，换网络再双击一次 `install.cmd`（重复装安全，不覆盖记忆）
- 二维码一直不刷新 → 关掉窗口重开
- QQ 发了不回 → 先看白名单里有没有你，群里还要先 @ 她
- 她像失忆了（记不住上一轮、五行不动）→ 先跑 `verify_install.ps1` 看「4.5 内核路径」段；再确认是从桌面「大肥鱼」进的，不是另起窗口

更多见 `常见问题.md`，以及安装根里的 `START-HERE.md`。

## 想从 GitHub 装？

做不到「丢个链接让 DSH 自己装好」——卡在 pnpm 会拦下 GitHub 插件的安装期构建脚本，必须先手写白名单再重跑。能到什么程度、为什么不会改坏 DSH，见同目录的 `从GitHub直接安装.md`。
