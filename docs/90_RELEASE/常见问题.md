# 常见问题

> 状态：**已对齐实装（V1）** ｜ 最后更新：2026-11-14
> 写给用户看，不出现工程术语。
>
> 前提：默认装在 `%USERPROFILE%\fishidian\`。如果你装到了别的盘，下面所有这个路径换成你的安装根。

## 她连不上 QQ 了

按顺序看，四个原因：

1. **二维码过期了** —— 码只有一分钟左右。窗口右下角点「连 QQ」，浮层上写"这个码可能过期了"就点一下刷新
2. **NapCat 没起** —— 任务管理器里有没有一个 `node.exe` 命令行带 `qq-qrcode-server.js`；`%USERPROFILE%\NapCat\cache\qrcode.png` 在不在
3. **版本对不上** —— 双击安装根里的 `check_napcat.ps1` 体检，它会报 NapCat 和本机 QQ 两个 build 号。**不一致不代表不能用**，先真起一次看码出不出来；出不来再去 [NapCat 的 Releases 页](https://github.com/NapNeko/NapCatQQ/releases) 换一个版本
4. **被杀毒软件拦了** —— 见下一条

## 杀毒软件拦住了她

她需要注入 QQ 进程拿消息，360、火绒这些可能会拦，甚至直接删文件。

做法：把整个 `fishidian` 安装文件夹、`%USERPROFILE%\NapCat\`、以及你本机的 QQ 都加到杀毒软件白名单。一般在"设置 → 白名单 / 信任列表"。

## 想换一个 QQ 号

改一个文件：`%USERPROFILE%\fishidian\data\profiles\desktop\cordis.patch.yml`

改这两处：`botQq`（新号）、`allowUsers`（新号也加进去，不然自己都聊不了）。然后关掉她的窗口重新打开，右下角重新点「连 QQ」扫一次码。

**之前的聊天和记忆都不受影响** —— 记忆库是分开存的。

## 想让她也能跟别人说话

同一个文件，`allowUsers` 里加对方的 QQ 号，用 YAML 列表格式：

```yaml
allowUsers:
  - "你的号"
  - "对方的号"
```

加完重启她的窗口。对方的号在他自己的 QQ 资料页能看到。

## 她突然不说话了

窗口里敲 `/state`，看两处：

- **熔断** 挂了 —— 说明触发了保护（比如情绪过载），等十几分钟自己会恢复
- **关系温度** 是"冷战" —— 她进入关系冷却了，正常聊几句会慢慢回来

`/proactive` 能看她想不想主动找你、三个因子各是多少。

如果 QQ 里不回，先看白名单里有没有你；群里还要先 **@ 她**（默认只有被 @ 才回）。

## 想让她彻底消失

删掉 `%USERPROFILE%\fishidian\` 整个目录，再删桌面快捷方式。

**这会连记忆库一起删掉。** 想留着记忆就先备份这两个目录：

- `%USERPROFILE%\fishidian\workspace\`
- `%USERPROFILE%\fishidian\config\`

（装完重装一次 `install.cmd`，再把这两个目录拷回去就恢复了。）

## 电脑换了一台，她还记得以前的事吗

不会——记忆只存在原来那台电脑上。

想搬过去：

1. 新电脑上先完整装一次（双击 `install.cmd`）
2. **两台机器的窗口都先关掉**，把老机器的 `workspace\` 和 `config\` 覆盖到新机器的同位置
3. 打开窗口，`/memory` 能看到老机器那些记忆

⚠️ 别只拷 `dfy.db` 一个文件到正在运行的库上 —— 数据库有 WAL 缓存，热拷会漏数据、而且不报错。要拷就整目录拷、并且先关窗口。

## 装完想重装

直接再双击 `install.cmd`。它只换程序文件，`workspace\` 和 `backup\` 一律不动，**记忆不会被覆盖**。

## 还是不行

把 `%USERPROFILE%\fishidian\logs\` 里最近那几份日志附上（里面有你的 QQ 号，贴之前自己扫一眼），去 [GitHub 仓库](https://github.com/AnJianY00/fishidian/issues) 开个 Issue，写清卡在哪一步、屏幕上原话是什么。

装不上的报错、她不该有的反应、文档写错的地方、你觉得该换个做法的设计 —— 都算，不用客气。
