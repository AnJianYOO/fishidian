# 11 目录与数据

> 状态：有效 ｜ 最后更新：2026-11-14 ｜ 对应版本：V1
> 只讲现在是什么样。为什么这么定，记在内部决策记录里（未随仓库公开）。版本替换细节见 `13`。

## 1 装在哪

**`%USERPROFILE%\fishidian\`** —— 例如 `C:\Users\<用户名>\fishidian\`

不装在 Program Files（有 UAC 保护，她每天写日志和记忆，放那儿会天天出问题），不装 ProgramData（全机器共享，多账户会串记忆）。

安装根的名字可以用 `install_v1.ps1 -TargetRoot` 改，下文按默认名写。

## 2 目录结构

```
%USERPROFILE%\fishidian\
├─ data\                     DSH_HOME，程序数据
│   ├─ profiles\desktop\     她这个实例的 profile（cordis.patch.yml、QQ 号、白名单）
│   └─ electron-data\        窗口缓存
├─ workspace\                她的全部东西
│   ├─ memory\               记忆库 dfy.db
│   │   └─ snapshots\        快照
│   ├─ sessions\             对话记录
│   ├─ notes\                笔记
│   └─ files\                收发的文件
├─ fishidian-core\           内核（安装时从包里的 payload\ 拷进来）
├─ dsh-fishidian\            插件壳
├─ dsh-client-ui-fatfish\    皮肤
├─ dsh-qq-onebot-bridge\     QQ 桥
├─ tools\                    qq-qrcode-server.js
├─ config\                   配置（setup.json 在这）
├─ backup\                   备份：daily\ / weekly\ / manual\
├─ logs\                     四类：app\ / error\ / bridge\ / audit\
├─ launch.ps1
├─ check_napcat.ps1
├─ verify_install.ps1
├─ python-path.txt           安装时探测到的 Python 绝对路径（launch.ps1 读它）
└─ README.md / README.txt / START-HERE.md / FOR-AI.md / VERSION.txt
```

## 3 各目录的职责边界

| 目录 | 谁能写 | 能不能手动删 |
| --- | --- | --- |
| `data\` | 程序 | 不建议，删了要重新登录 |
| `workspace\` | 她 | 能，但删了记忆就没了 |
| `fishidian-core\` 等四个模块目录 | 安装程序 | 能，删了重装即可 |
| `tools\` | 安装程序 | 能，重装恢复 |
| `config\` | 程序 + 设置页 | 不建议 |
| `backup\` | 程序 | 不建议 |
| `logs\` | 程序 | 能，会自动重建 |

## 4 单一事实源

**`config\setup.json` 是唯一可编辑的配置源。**

```
config\setup.json（人可读、设置页可写）
        │
        ├── 启动时渲染 → data\profiles\desktop\cordis.patch.yml
        └── 换号流程   → NapCat\config\napcat_<QQ号>.json
```

其余几处全部是程序生成的产物，手动改了会在下次启动时被覆盖回去。运行时快照（`qq-runtime.json`）同理，绝不能当持久层用。

## 5 目录什么时候生成

- **安装时**：目录骨架 + 四个模块 + 启动脚本 + 安装根文档 + `VERSION.txt` + `README.txt` + `setup.json` 占位
- **首次启动时**：`workspace\memory\dfy.db` 在这时候才由内核创建

这样新装出来一定是空库，重装时骨架不动、记忆原地保留。

## 6 编码与路径的三个约束

1. 安装根和所有子目录用 ASCII 名（`fishidian`、`data`、`workspace` …），路径里不出现中文。脚本一律 UTF-8 无 BOM，PowerShell 一律 `-LiteralPath`
2. 目录层级控制在四层以内，避开 Windows 260 字符限制
3. 绝不放进 `Documents\`（OneDrive 默认同步区，db 会天天冲突）

## 7 磁盘增长

日志 7/30 天、备份 7 日备 + 4 周备，看着不多，但 `workspace\files` 里的图片视频会一直堆。整个目录超过 2 GB 时在日志里记一条提醒，不做自动删。
