# 小鱼 · fishidian

**一个用中医经络和五行来整理记忆的 AI 好友。**

现在的陪伴类 AI，记忆基本是一堆向量：说过的每句话切成小块，算相似度，挑最像的几条塞回提示词。结果是——她记得你用过哪些词，却不记得你们之间发生过什么；也分不清「三个月前随口提的一句」和「昨天认真说过的话」。

小鱼不走这套。每条记忆都归到一条经络上、带一个五行属性；要用的时候不靠相似度去捞，而是看她此刻是什么状态：情绪在哪一档、你们的关系是冷是热、这条记忆的"火候"攒够了没有。同一句话隔一个月再提，浮上来的东西可能完全不同；久不碰的会慢慢沉下去，反复被印证过的会往上走。

顺便说几件她的事：

- 记忆就是一个 SQLite 文件，拷走、备份、换台电脑都行
- 有自己的窗口，跟你工作用的 DSH 各过各的，互不打扰
- 能接 QQ，你在手机上也能跟她说话
- 内核只用 Python 标准库，没有向量库，也不用挂 embedding 服务

只在 Windows 上跑过，macOS 和 Linux 没适配。

> **现在到哪一步**：v0.1.0 能从头跑到尾——装包、开窗口、聊天、记忆落进库、QQ 收发回来。但还在做，看图、本地跑模型这些都还没有。
>
> **哪里有不对，都欢迎开 [Issue](https://github.com/AnJianYOO/fishidian/issues)**：装不上、她不回、文档写错、或者你觉得哪个设计该换个做法 —— Bug 和建议一样收。不保证每条都回，但每条都会看。

## 装之前，先备齐四样

1. **DeepSeek Harness（DSH）桌面端**，并且登录过一次
   不用另外准备 API Key，登录一次它就自己记住了。装之前记得把它**连托盘一起退掉**——开着装会卡在第一步。
2. **Node.js 18 以上**
   16 也装得上，但 QQ 通道起不来。
3. **Python 3.8 以上**，安装时勾上 `Add python.exe to PATH`
   想确认装没装对：命令行敲 `python`，如果弹出微软商店，说明你装的是个占位程序，得重装。
4. **一个 QQ 号**，用来当她
   不想接 QQ 的话，这一项可以跳过。

少一样，安装器第一步就会说清缺哪个、去哪装，不会装一半坏掉。

## 装上

1. 去 [Releases](https://github.com/AnJianYOO/fishidian/releases) 下最新的 `fishidian-v0.1.0-*.zip`
2. **先解压**（右键 → 全部解压缩）。别在压缩包里直接双击安装脚本
3. 双击解压出来的 `install.cmd`，按提示填两个 QQ 号：机器人用一个，你自己用一个
4. 等九步跑完，桌面会多一个「小鱼」图标

程序会装在 `%USERPROFILE%\fishidian\`，装完那个解压文件夹就可以删了。

## 装完是什么样

双击桌面那个图标，等 5 到 20 秒，会开出一个单独的窗口。

这个窗口、这套记忆，都是她自己的。你在工作用的 DSH 里聊的东西不会进她的记忆，她也不会去翻你的工作资料——两个实例各有各的 home 目录，各有各的库。

装出来的文件夹里还有几份说明：

| 文件 | 给谁看 |
|---|---|
| `START-HERE.md` | 你，从装到验收，一步一步 |
| `README.md` | 你，使用手册 |
| `FOR-AI.md` | 让 AI 替你装、替你排错时给它看 |
| `VERSION.txt` | 装了哪些模块、什么版本 |
| `README.txt` | 目录说明：`workspace` / `logs` / `backup` 各放什么 |

QQ 那份（`QQ桥怎么用.md`）打包在 zip 里，装完不会拷过来。要看的时候回压缩包找，或者看仓库里的 [`docs/90_RELEASE/QQ桥怎么用.md`](docs/90_RELEASE/QQ桥怎么用.md)。

## QQ 怎么接

QQ 是可选的。不接，窗口里照样能聊。

默认走 NapCat + [`dsh-qq-onebot-bridge`](https://github.com/cheesehaqi/dsh-qq-onebot-bridge)（第三方开源，MIT）。桥对外是标准 OneBot 11 反向 WebSocket：桥在这台电脑上开着 `ws://127.0.0.1:6700` 等，由 OneBot 那边连过来。

所以想换别的实现（Lagrange.OneBot、LLOneBot、自己写一个），是在**那个实现的反向 WS 里填 `ws://127.0.0.1:6700`**，桥这边不用动。这条是按协议写的，目前只在 NapCat 上验证过。

完整步骤、换实现的办法、连不上按什么顺序查，都在 [`QQ桥怎么用.md`](docs/90_RELEASE/QQ桥怎么用.md) 里。不想接 QQ，安装时机器人号直接回车就行。

## 几个词的意思

第一次打开会看到几个不常见的词，先对一下：

- **记忆池**：所有记忆都在一个 SQLite 里，按档分层。越靠上的档越容易被想起来，久不用的往下沉。`/状态` 能看到每档现在有多少条。
- **五行**：金木水火土。每条记忆带一个，她自己也有一个当前状态。两边怎么碰上，决定这条记忆这会儿该不该冒出来，也影响她说话的口气。
- **先天锚**：按出生信息算出来的一个固定偏移，让她的底色不是随机的。
- **冷战**：一种关系状态。闹了别扭会进冷却，这阵子她不会主动找你、说话也淡，过一阵自己缓过来。
- **表达层**：语气和分段不是写死的模板，是从当前状态推出来的。所以同一个人心情不一样，说的话长度和节奏也不一样。

## 目录结构

```
fishidian-core/          内核：记忆怎么存、五行怎么算、话怎么组织（只用标准库）
dsh-fishidian/           DSH 插件：把内核接到对话里，管注入和命令
dsh-client-ui-fatfish/   皮肤：左栏和窗口长相
fatfish-window/          独立窗口的配置模板
tools/                   安装、启动、验证、打包的脚本
docs/                    设计文档和安装说明
```

QQ 桥没有单独建库。它是别人的项目，直接指向上游；本版安装包里带了一份基于上游 v0.8.9 改过的，仓库里不放桥的源码。

## 说明与免责

- **五行和经络在这里是整理记忆的办法**，是一套参数，不是中医诊断，也不构成任何健康建议。身体不舒服请去医院。
- **她不是心理治疗，也做不了危机干预。** 她能陪你说话，但替代不了专业帮助。状态不好的时候，找真人。
- **代码主要由 AI 辅助生成。** 架构、取舍，以及每条功能在实际环境里的验证是人做的（内核 444 条断言、安装包 53 项自检）。所以代码风格不一定统一，也可能留着我没看出来的坑——看到就提 Issue，这类反馈我改得快。
- **数据都在你自己机器上。** 对话走你自己登录的 DSH，这个项目不收集、不上传任何东西。记忆库就是 `%USERPROFILE%\fishidian\` 下的一个 SQLite，随时能拷走或删掉。
- 个人项目，按现状提供，不承诺稳定性。用之前自己掂量。
